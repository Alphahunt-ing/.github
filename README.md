# Alphahunt-ing/.github

The organization profile for [Alphahunt-ing](https://github.com/Alphahunt-ing).
`profile/README.md` is what GitHub shows on the organization page; `assets/`
holds its banner, the organization avatar and the logo.

The banner, avatar and logo are rendered in
[`Alphahunt-ing/website`](https://github.com/Alphahunt-ing/website) by
`tools/render-og.sh` (sources: `tools/banner-render.html`,
`tools/avatar-render.html`, `assets/favicon.svg`; the logo is `icon-512.png`).
Re-render there and copy them here; do not edit the PNGs by hand. The avatar is
uploaded by hand at `github.com/organizations/Alphahunt-ing/settings/profile`:
GitHub has no API for it.
